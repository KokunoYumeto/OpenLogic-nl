\olchapter{fol}{byd}{Voorbij de eerste-ordelogica}

\begin{editorial}
  Dit hoofdstuk, bewerkt naar Jeremy Avigads aantekeningen over logica,
  geeft een uiterst beknopt overzicht van andere logische systemen. Het
  is bedoeld om in een cursus die deze systemen niet behandelt,
  onderwerpen voor verdere studie aan te reiken. Elk onderwerp dat
  hier wordt genoemd, zal---hopelijk---uiteindelijk in een eigen deel
  van het Open Logic Project worden behandeld.
\end{editorial}
