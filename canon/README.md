# Geraadpleegde bronnen

De passage-ID’s komen uit de geaccepteerde segmentregistratie. `GERAADPLEEGDE_PASSAGES.jsonl` bewaart de vindplaats en hash van iedere gekoppelde passage. `BRONNEN.jsonl` geeft beschikbare bibliografische gegevens en openbare links.

De oorspronkelijke passagebestanden blijven behouden in het productiearchief. Ze zijn hier niet integraal overgenomen: publieke toegang tot een tekst is niet automatisch toestemming om die tekst opnieuw te verspreiden. De verwijzingen bewijzen op zichzelf geen correcte vertaling. Alle keuzes blijven corrigeerbaar.
