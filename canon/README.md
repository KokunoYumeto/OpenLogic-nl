# Geraadpleegde bronnen

De passage-ID’s komen uit de geaccepteerde segmentregistratie en het openbare
keuzeregister. `GERAADPLEEGDE_PASSAGES.jsonl` bewaart de vindplaats en hash van
iedere van de 454 gekoppelde passages. `BRONNEN.jsonl` geeft de beschikbare
bibliografische gegevens en openbare links voor 92 bronnen.

De oorspronkelijke passagebestanden blijven in het afgeschermde
productiearchief. Ze zijn hier niet integraal overgenomen: publieke toegang tot
een tekst is niet automatisch toestemming om die tekst opnieuw te verspreiden.
De verwijzingen bewijzen op zichzelf geen correcte vertaling. Alle keuzes
blijven corrigeerbaar; exacte gekozen formuleringen, locaties en vragen staan
in `provenance/KEUZEREGISTER_192.jsonl`.
